# Contributing to Awesome TON

Thanks for proposing an addition. The list is a curated public-domain resource — every entry should be useful to a real human navigating the TON ecosystem.

## Format

One bullet per entry, single line, under 140 characters:

```
- [Name](https://link) — short factual description of what it is.
```

- **Name** — official project name, not marketing slogan.
- **URL** — primary domain or canonical landing page. No tracking parameters.
- **Description** — what it actually does. Avoid words like "best", "leading", "revolutionary".

## Acceptance criteria

We accept entries that meet all of:

- **Real** — the project is live and accessible (we will check the URL).
- **TON-relevant** — directly touches TON blockchain, jettons, NFTs, mini-apps, or TON-adjacent infrastructure.
- **Useful** — solves a problem a TON user / developer actually has.
- **Independent** — not paid placement, not affiliate-only.

We reject entries that are:

- Pure promotional pages with no real product behind.
- Token-launch landing pages with no working app.
- Duplicates of existing entries (open an issue first if you think yours adds value).
- Anything looking like a phishing / drainer / scam.

## How to submit

1. Fork the repo.
2. Add your entry in the right section (alphabetical order within section is nice but not required).
3. Open a PR. One PR per category.
4. In the PR description, link to the project, briefly say what it does, and mention any obvious conflict of interest.

## Maintenance

Maintainers can edit, reorder, or remove entries to keep the list useful. Removed entries may include broken URLs, dead projects, or anything that no longer fits the criteria above.
